# CrewPulse — Onboard Health Companion

NASA Space Apps Challenge 2026 · *Create Health Monitoring Software for Astronauts on Space Missions*

CrewPulse helps astronauts assess their own health on long missions: an interactive body map, large color-coded vital-sign tiles (manual entry or live sensors), and delay-aware triage that tells the crew when to act alone and when to call the flight surgeon.

## Run locally

```bash
npm install
npm run dev
```

## Notes
- Values tagged SAMPLE or SIMULATED are not real measurements.
- CrewPulse supports self-assessment; it does not diagnose.
